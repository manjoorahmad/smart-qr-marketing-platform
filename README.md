Smart QR Marketing Platform

A web-based QR marketing platform that allows users to create marketing campaigns, generate QR codes, track scans, and monitor campaign performance through an analytics dashboard.

✨ Features

- User Signup and Login
- Create, Update, and Delete Campaigns
- QR Code Generation and Download
- QR Scan Tracking
- Analytics Dashboard
- Campaign Search and Status Filter
- JWT Authentication
- User-wise Data Security

🛠️ Technologies Used

- Frontend: Next.js, React, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT
- QR Code: QR Code Generation Library

⚙️ Project Setup

1. Clone this repository.
2. Install dependencies in the frontend and backend folders.
3. Configure environment variables.
4. Start the backend and frontend servers.
